Conversations that keep going.

One focused Turn, other work continuing in the background, and an honest view of what is running, waiting, finished or interrupted.

01Long-running conversations

Continue a Turn across messages while preserving its native Agent session and conversation history.

02Concurrent work

Create explicit parallel Turns. Switch focus without cancelling the work already running.

03Mid-task guidance

Guide the target Turn through native steering or its Agent's declared safe boundary. Tool work may finish its current step first.

04Persistent Python

Optional session-owned Python kernels retain variables across calls, with fresh state for parallel Turns and Branches.

05Structured execution

Run bounded Python-assisted subtasks with typed output validation, approvals and constrained containers.

06Honest recovery

Keep partial output and check native session truth. Unknown side effects are never automatically replayed.

Download and run locally.

Clone the current source and start Web/API together on ports 3000/8000. Windows and Linux setup instructions are in the README. Optional Python tools require a Linux Docker engine; Windows uses Docker Desktop with Linux containers.

Beta software: review Agent actions and use disposable workspaces for evaluation. Reconnecting a session does not guarantee interrupted work can resume. Live Python state does not survive a worker restart.
